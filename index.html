Amazon Finance Dashboard

A private, locally-run profitability tool for a single Amazon UK wholesale seller.

This is not a public product. It is a personal tool, run by its owner on their own computer. There is no hosted service, no sign-up, and no multi-user version. It is not offered for use by anyone else.

What it does

It joins actual wholesale purchase costs to actual Amazon sales data so the operator can see real per-product and business-level profit, rather than estimates.

  • Reads supplier invoices from a single, specific label in the operator's own Gmail mailbox
  • Extracts purchase quantities, net cost, VAT and unit cost from those invoices
  • Combines that with the operator's own Amazon Selling Partner API data (orders, fees, refunds, shipping charges)
  • Calculates profit, margin and ROI, and displays it on a dashboard that runs only on localhost

Why it requests Gmail access

Supplier invoices arrive by email. The application needs to read the messages under one label to obtain the invoice attachments that contain purchase costs. It requests exactly one Google permission:

https://www.googleapis.com/auth/gmail.readonly
Read-only. The application cannot send, reply, modify, archive, label or delete anything in the mailbox.

Where the data goes

Nowhere. Email content, invoices and all derived financial figures are stored in a local database and local files on the operator's own machine. Nothing is uploaded, shared, sold, or transmitted to any third party or to the developer.
