Privacy Policy

Amazon Finance Dashboard · Last updated: 4 October 2026

Summary. This application runs entirely on one person's own computer. It reads that person's own Gmail invoices with read-only permission, stores everything locally, and transmits nothing to the developer or to any third party. There is no server, no analytics, and no account.

1. Who this applies to

Amazon Finance Dashboard ("the application") is a personal, single-user tool used by its owner and operator to analyse the profitability of their own Amazon UK wholesale business. It is not a hosted service and is not made available to other users. The only person whose data the application handles is the operator, who is also the person who installed and authorised it.

2. What the application accesses

With the operator's explicit authorisation, the application requests one Google permission:

https://www.googleapis.com/auth/gmail.readonly

This read-only scope is used solely to:

  • list the labels in the operator's own mailbox, in order to locate the single label containing supplier invoices;
  • read the metadata of messages under that label (date, sender, subject, message identifier);
  • download the invoice attachments on those messages, which contain wholesale purchase costs.

The application cannot send, reply to, forward, modify, label, archive or delete email. It does not read messages outside the configured invoice label for any purpose other than resolving the label itself.

3. What is stored, and where

All data is stored on the operator's own computer. Specifically, a local SQLite database file and a local directory of downloaded invoice files. This includes:

  • Gmail message identifiers, dates, sender addresses and subject lines for invoice emails
  • The original invoice attachments, kept unmodified as accounting evidence
  • Supplier, product, quantity, cost and VAT figures extracted from those invoices
  • Amazon order, fee, refund and shipping data obtained from the operator's own Amazon Selling Partner API account
  • Calculated profit figures derived from the above

The OAuth token issued by Google is stored in a local file readable only by the operator's own user account. The operator's Google password is never requested, received, or stored — authentication happens entirely on Google's own sign-in pages.

4. What is not done with the data

  • It is not transmitted to the developer.
  • It is not sent to any third-party service, server or API, other than Google and Amazon themselves when retrieving the operator's own data.
  • It is not sold, rented, shared, published or used for advertising.
  • It is not used to train machine learning models.
  • No analytics, telemetry, crash reporting or usage tracking of any kind is collected.

5. Limited Use compliance

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to provide the invoice-cost feature described above, is not transferred to others, is not used for advertising, and is not read by humans except as required for the operator's own accounting purposes, to resolve a technical fault, or where required by law.

6. Data retention and deletion

Because all data resides on the operator's own machine, the operator controls retention entirely. Data is removed by deleting the local database file and the local invoice directory.

Google access can be withdrawn at any time, independently of this application, at myaccount.google.com/permissions. Deleting the locally stored token file also ends the application's access until it is re-authorised.

7. Security

  • Access is read-only by design; the narrowest sufficient Gmail scope is requested.
  • Credential and token files are written with owner-only file permissions.
  • Access tokens are filtered out of application logs.
  • The application binds only to localhost and is not exposed to any network.

No system is perfectly secure. As this is a personal tool running on personal hardware, its security also depends on the operator keeping their own device and Google account secure.

8. Children

The application is a business accounting tool and is not directed at or intended for use by children.
